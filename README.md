## 知识库结构

- `knowledge-base/00-使用说明` 放阅读路线、证据规则和版本边界。
- `knowledge-base/01-角色与市场` 拆解不同公司的 FDE 组织方式。
- `knowledge-base/02-交付方法` 给出从发现、评测、上线到交接的操作方法。
- `knowledge-base/03-海外案例` 收录八个有公开来源的详细案例。
- `knowledge-base/04-工程资源` 解释 GitHub 项目怎样进入真实交付。
- `knowledge-base/05-职业发展` 汇总岗位样本、能力证据和面试准备。
- `knowledge-base/06-产品运营` 维护数字产品的授权、更新与售后边界。
- `templates` 保存可复制的项目模板。
- `research` 保存公开来源索引、检索记录和事实台账。
- `manuscript` 是《FDE 橙皮书》可维护主稿。
- `dist` 是已经生成的 DOCX 与 PDF。

## 案例怎样读

案例不会假装知道企业没有公布的内部细节。每篇都分成公开事实、FDE 视角重构、可复用做法和资料缺口。重构部分是依据公开流程做的专业分析，不代表企业官方复盘。
