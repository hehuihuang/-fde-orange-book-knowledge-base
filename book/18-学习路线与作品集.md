# 第 18 章　学习路线与作品集

学习 FDE 可以围绕一项小型交付展开。课程提供概念和练习，作品则检验你能否处理需求、数据、失败和交接。两者需要结合。

## 按缺少的能力选择课程

下列入口在本次编写时已核查。课程开放方式、费用、账号与证书条件可能变化，应以官方页面为准。本书不承诺就业或认证结果。

| 学习目的 | 官方资料 | 学完后应留下什么 |
| --- | --- | --- |
| 业务对象与用例界定 | Palantir AIP 入门与 Scoping Use Cases | 一页用例与对象关系图 |
| 理解 Agent 的运行方式 | Hugging Face Agents Course | 带工具与停止条件的小应用 |
| 选择简单工作流 | Anthropic 工程文章 | 一份架构取舍说明 |
| 调试与评测 Agent | DeepLearning.AI 与 Arize 课程 | 测试集、评分器与实验报告 |
| 理解接口连接 | MCP 官方文档 | 工具接口与权限说明 |

Palantir 的入门路线连接用例界定与实际工作流，适合学习平台如何服务业务。Hugging Face 课程包含框架和实践任务，适合具备基础 Python 能力的读者。DeepLearning.AI 的评测课程覆盖可观测性、组件评测与结构化实验。只完成其中一项，仍不足以证明可以独立交付生产系统。

## 一条可调整的学习安排

第一阶段观察真实任务并取得合法样本，留下流程、基线与权限范围。第二阶段完成最小应用，把数据、检索或工具调用接起来。第三阶段建立测试与运行记录，故意模拟失败。最后请其他人试用，并完成交接说明。

可以按自己的可用时间安排，不必把某个固定天数当作能力保证。每一阶段的出口由作品决定。应用能够运行但没有评测，就继续补评测；演示顺利但用户无法自行使用，就继续改交互和说明。

## 作品集应该让人核查

一份有说服力的作品集包括问题背景、授权范围、方案取舍、运行方法、失败样本和结果限制。演示视频可以辅助理解，但要说明哪些部分为模拟数据，哪些已经实际验证。

公开发布时，不上传客户数据、凭据、私人会议或未授权材料。可以用明确标注的合成数据展示技术流程，但不能据此声称取得了真实业务收益。

## 怎样使用 X 与社区

X 适合发现招聘、工程师讨论和新材料。本次检索到 Speechmatics 发布过包含 FDE 的岗位信息。这能作为岗位线索，不能用于推算行业规模或平均薪酬。看到效果数字后，应继续寻找公司原文、技术说明或正式文件。

国内实践可从 Datawhale FDE100 开始。范冰的公开 FDE 指南也值得作为延伸阅读，但其版权声明限制商业用途。本书只链接原作。

## 本章交付物

把学习计划改写成四次可展示的提交，每次说明新增了什么能力和证据。最后请别人从空白环境复现项目，记录他遇到的问题并修正。
