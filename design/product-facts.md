## 当前项目

- 项目为用户维护的中文 FDE 图书，非 Palantir、OpenAI、Anthropic 或 Datawhale 官方出版物。
- 现有版本含书稿、八篇海外案例与后补充的社区材料。重编将保留原文件，以 book/ 下的独立章节作为新版内容来源。
- 用户授权公开仓库发布；本次不公布凭据、私人访谈、社区全文或未获授权的第三方书稿。

## 参考资料

- [Datawhale FDE100](https://fde100.datawhale.cn/cases) 页面本次读取显示 24 条案例。品牌中的 100 不等于当前已公开完整案例数。
- [范冰的 FDE 指南](https://github.com/xdash/FDE-the-Guidance-Book-of-Forward-Deployed-Engineer) 提供按章 Markdown 与整本 PDF。其 README 对商业用途要求书面许可。本项目仅链接推荐，不复制或改编其正文。
- [Anthropic 的工程文章](https://www.anthropic.com/engineering/building-effective-agents) 区分预定义工作流与模型动态决策的 Agent；原文注明工具生态已经变化。本书采用稳定概念，不照搬旧版本代码。
- [Palantir 官方入门](https://www.palantir.com/docs/foundry/aip/getting-started-with-aip)、[Hugging Face Agents Course](https://huggingface.co/learn/agents-course/unit0/introduction) 与 [DeepLearning.AI 评测课程](https://www.deeplearning.ai/courses/evaluating-ai-agents) 用于学习路线。开课、费用、账号条件以官网为准。
- [Speechmatics 的 X 招聘帖](https://x.com/Speechmatics/status/2030980311022985622) 只证明发布方曾公开招聘该岗位，不能证明行业人数、薪酬或交付效果。

## 编辑约束

基础章节属于本书方法建议；案例中的企业数字只保留必要且可追溯的部分。供应商客户故事与独立审计分开。所有教学方案明确标注本书分析，不假装知道客户内部架构。章节源文件、HTML 与 PDF 使用同一份目录清单构建。
