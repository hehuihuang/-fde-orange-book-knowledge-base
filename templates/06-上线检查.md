# 上线检查

## 业务与范围

- [ ] 业务负责人签署指标、范围和责任。
- [ ] 试点用户、任务、地区和期限明确。
- [ ] 停止和退出条件明确。

## 数据与安全

- [ ] 数据来源、所有者、允许用途和保留周期确认。
- [ ] 用户、服务账号、租户和最小权限测试通过。
- [ ] 提示注入、越权、泄露和工具滥用测试完成。
- [ ] 日志与 Trace 没有不必要的敏感正文。

## 质量与运行

- [ ] 核心评测与高风险切片达到门槛。
- [ ] 延迟、并发、成本和供应商限额压测完成。
- [ ] 超时、重试、幂等和部分失败经过测试。
- [ ] 监控、告警、值班和事故升级已经生效。

## 控制与交接

- [ ] 人工确认、升级和申诉实际演练。
- [ ] 灰度、功能开关、降级和回滚实际演练。
- [ ] 用户培训、支持入口和手工流程明确。
- [ ] 客户团队能查看监控并处理常见事件。
